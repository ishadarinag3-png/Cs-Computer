# Computer Fundamentals & Electronics Academy (ਕੰਪਿਊਟਰ ਅਤੇ ਇਲੈਕਟ੍ਰਾਨਿਕਸ ਅਕੈਡਮੀ)

A production-grade, bilingual (**Punjabi Gurmukhi + English**) full-stack Computer Science, Electronics, and Discrete Mathematics learning platform built with **React 19**, **TypeScript**, **Tailwind CSS**, **Express**, **Cloud SQL for PostgreSQL**, **Drizzle ORM**, **Firebase Authentication**, and **Gemini AI (`@google/genai`)**.

---

## Architecture & Curriculum Overview

### 13-Level Complete Bilingual Curriculum (26 Authoritative Lessons, 26 Quizzes, 260 Assessment Questions, 129 Blueprint Topics with 100% Verified Coverage)

1. **Level 0: Mathematics and Physics for Electronics (ਲੈਵਲ 0: ਗਣਿਤ ਅਤੇ ਭੌਤਿਕ ਵਿਗਿਆਨ)**
   - **Lesson 0.1**: Arithmetic, Algebra, SI Units, Decibels & Trigonometry
   - **Lesson 0.2**: Calculus, Complex Phasors & Electromagnetic Field Physics
2. **Level 1: Electrical Fundamentals (ਲੈਵਲ 1: ਬਿਜਲਈ ਬੁਨਿਆਦਾਂ)**
   - **Lesson 1.1**: Voltage, Current, Resistance, Ohm's Law & Kirchhoff's Laws (KCL / KVL)
   - **Lesson 1.2**: Alternating Current (AC), RMS Power, Grounding & Electrical Safety
3. **Level 2: Passive Components (ਲੈਵਲ 2: ਪੈਸਿਵ ਕੰਪੋਨੈਂਟਸ)**
   - **Lesson 2.1**: Resistors, Potentiometers, Colour Codes, Power Ratings & Thermistors
   - **Lesson 2.2**: Capacitors, Inductors, RLC Resonance, Transformers & Relays
4. **Level 3: Semiconductor Devices (ਲੈਵਲ 3: ਸੈਮੀਕੰਡਕਟਰ ਯੰਤਰ)**
   - **Lesson 3.1**: Semiconductor Physics, Doping, Diodes, Zener, Rectifiers & Optocouplers
   - **Lesson 3.2**: Transistors: BJT Biasing, MOSFETs, JFETs, IGBTs & Thyristors
5. **Level 4: Analog Electronics (ਲੈਵਲ 4: ਐਨਾਲਾਗ ਇਲੈਕਟ੍ਰਾਨਿਕਸ)**
   - **Lesson 4.1**: Transistor Small-Signal Amplifiers, Biasing & Negative Feedback
   - **Lesson 4.2**: Operational Amplifiers, Active Filters, Schmitt Triggers & Oscillators
6. **Level 5: Digital Electronics (ਲੈਵਲ 5: ਡਿਜੀਟਲ ਇਲੈਕਟ੍ਰਾਨਿਕਸ)**
   - **Lesson 5.1**: Binary, Hexadecimal, Boolean Algebra, Truth Tables & Karnaugh Maps
   - **Lesson 5.2**: Combinational & Sequential Logic: Adders, Flip-Flops, Counters & FSMs
7. **Level 6: Power Supplies & Power Electronics (ਲੈਵਲ 6: ਪਾਵਰ ਸਪਲਾਈ ਅਤੇ ਪਾਵਰ ਇਲੈਕਟ੍ਰਾਨਿਕਸ)**
   - **Lesson 6.1**: Linear Voltage Regulators (78xx / LM317), LDOs & Thermal Management
   - **Lesson 6.2**: Switch-Mode Converters (Buck, Boost, Flyback), BMS, LiFePO4 & Inverters
8. **Level 7: Measurements and Instrumentation (ਲੈਵਲ 7: ਮਾਪ ਅਤੇ ਇੰਸਟ੍ਰੂਮੈਂਟੇਸ਼ਨ)**
   - **Lesson 7.1**: Digital Multimeters, True RMS, 10MΩ Loading & 4-Wire Kelvin Measurements
   - **Lesson 7.2**: Digital Storage Oscilloscopes, 10X Probe Compensation, Logic Analyzers & CAT Safety
9. **Level 8: Microcontrollers and Embedded Systems (ਲੈਵਲ 8: ਮਾਈਕ੍ਰੋਕੰਟਰੋਲਰ ਅਤੇ ਇੰਬੈੱਡਡ ਸਿਸਟਮ)**
   - **Lesson 8.1**: MCU Architecture (Harvard vs Von Neumann), GPIO, Pull-ups & Hardware ISRs
   - **Lesson 8.2**: Hardware Timers, PWM, 12-Bit SAR ADC, Serial Protocols (UART, SPI, I2C, CAN) & Bootloaders
10. **Level 9: PCB Design & Engineering Workflow (ਲੈਵਲ 9: PCB ਡਿਜ਼ਾਈਨ ਅਤੇ ਇੰਜੀਨੀਅਰਿੰਗ ਵਰਕਫਲੋ)**
    - **Lesson 9.1**: Schematic Capture, IPC Footprints, 4-Layer Stackup & 50Ω Controlled Impedance
    - **Lesson 9.2**: Design for Manufacturing (DFM/DFA), Gerber RS-274X, SMT Stencil Reflow & Inspection
11. **Level 10: Communications and Signal Processing (ਲੈਵਲ 10: ਸੰਚਾਰ ਅਤੇ ਸਿਗਨਲ ਪ੍ਰੋਸੈਸਿੰਗ)**
    - **Lesson 10.1**: Modulation Schemes (AM, FM, QAM), Shannon Capacity, Transmission Lines & RS-485
    - **Lesson 10.2**: RF Antennas, Path Loss, Wireless IoT (BLE, LoRa), Nyquist Theorem & Fast Fourier Transform (FFT)
12. **Level 11: Advanced Engineering (ਲੈਵਲ 11: ਐਡਵਾਂਸਡ ਇੰਜੀਨੀਅਰਿੰਗ)**
    - **Lesson 11.1**: Closed-Loop Control, PID Tuning, Anti-Windup, H-Bridge Motor Drivers & Stepper Microstepping
    - **Lesson 11.2**: Safety-Critical TMR Architecture, Dual-Core Lockstep, MTBF Reliability, FMEA & CE/FCC/RoHS Compliance
13. **Level 12: Practical Repair and Troubleshooting (ਲੈਵਲ 12: ਵਿਹਾਰਕ ਮੁਰੰਮਤ ਅਤੇ ਟ੍ਰਬਲਸ਼ੂਟਿੰਗ)**
    - **Lesson 12.1**: Systematic Fault-Finding, Cold Impedance Screening, Microvolt Delta Tracing & Thermal Imaging
    - **Lesson 12.2**: SMD/BGA Rework, IPC-7721 Pad/Trace Reconstruction, Solder Metallurgy (SAC305 vs Sn63) & Root Cause Analysis (RCA)

## Pedagogical Structure in Every Lesson

Every lesson includes strictly authored, non-placeholder educational sections:
- **Bilingual Titles & Objectives**: In English and authentic Punjabi Gurmukhi.
- **Child-Friendly Cultural Analogy**: Everyday Punjab life analogies (tube-well water pumps, farm tractors, hand-pumps, gurdwara sound systems).
- **In-Depth Technical Exposition**: Mathematical formulas, state transitions, circuit diagrams, and physical laws.
- **Worked Mathematical Problems**: Step-by-step calculations with Knowns, Formula, Substitution, Unit Verification, and Physical Interpretation.
- **Interactive Code / Script Demonstrations**: Production TypeScript/Python/SCPI snippets.
- **Common Misconceptions**: Myths debunked with scientific rationale in both English and Punjabi.
- **Technical Glossary (Terminology)**: English term, Punjabi transliteration, and bilingual definitions.
- **Authoritative Server-Enforced Quizzes**: 10 questions per lesson (20 per level), with 4 plausible options and comprehensive bilingual explanations.

## Security & Reliability Architecture

1. **Role-Based Access Control (RBAC)**:
   - Server-side verification via Firebase Admin SDK.
   - Admin authorization (`requireAdmin`) enforces trusted custom claims (`admin: true`) or verified server-side allowlist (`ADMIN_ALLOWLIST_EMAILS`). Substring email matching is prohibited.
2. **Payload Sanitization**:
   - Public `/api/curriculum` payloads strip `correctAnswer`, `explanationEn`, and `explanationPa` so answers cannot be inspected in client network traffic before submission.
3. **Timed Assessments & Anti-Farming Rules**:
   - Server computes quiz duration from session start; late submissions are marked expired.
   - Authoritative server-side grading against stored answers.
   - Duplicate lesson XP farming is prevented by checking previous completions.
4. **Authenticated AI Tutor**:
   - Learner identity derived exclusively from verified JWT tokens (`req.user.uid`), never request bodies.
   - Per-IP and per-user rate limiters with daily quotas and Zod schema validation.

## Installation, Migrations, Seeding & Testing

### 1. Install Dependencies
```bash
npm install
```

### 2. Apply Database Migrations
Applies transactionally version-controlled PostgreSQL migrations (`/drizzle/0000_initial_schema.sql`):
```bash
npm run db:migrate
```

### 3. Seed 13-Level Authoritative Curriculum
Idempotently loads all 13 courses, 26 lessons, 26 quizzes, 260 questions, and 6 achievements inside a single database transaction:
```bash
npm run db:seed
```

### 4. Run Automated Test Suite
Runs the 11 integration and security test suites using Vitest:
```bash
npm test
```

### 5. Typecheck & Build
```bash
npm run lint
npm run build
```

### 6. Start Server
```bash
# Development (Vite + Express on PORT || 3000)
npm run dev

# Production
npm start
```

## Rollback & Disaster Recovery Procedures

1. **Database Schema Rollback**:
   If a migration needs to be rolled back, revert the target Drizzle migration SQL file in `/drizzle/` and apply the reverse schema delta:
   ```bash
   # Revert to clean state and re-apply migrations
   npx drizzle-kit drop
   npm run db:migrate
   npm run db:seed
   ```
2. **Curriculum Seed Recovery**:
   `npm run db:seed` is idempotent and concurrency-safe. In the event of partial corruption or outdated course records, running `npm run db:seed` automatically purges obsolete courses and re-syncs all 13 courses and 26 lessons transactionally.
